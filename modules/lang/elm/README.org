* Description :unfold:
This module adds [[https://elm-lang.org/][Elm]] support to Doom Emacs.

** Maintainers
/This module has no dedicated maintainers./ [[doom-contrib-maintainer:][Become a maintainer?]]

** Module flags
- +lsp ::
  Enable LSP support for ~elm-mode~. Requires [[module::tools lsp]] and a langserver
  (supports [[https://github.com/elm-tooling/elm-language-server][elm-language-server]]).

** Packages
- [[package:elm-mode]]
- [[package:flycheck-elm]] if [[module::checkers syntax]]
