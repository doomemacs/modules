* Description :unfold:
This module adds support for the [[https://developer.apple.com/swift/][Swift programming language]] to Doom Emacs.

** Maintainers
*This module needs a maintainer.* [[doom-contrib-maintainer:][Become a maintainer?]]

** Module flags
- +lsp ::
  Enable LSP support for ~swift-mode~. Requires [[module::tools lsp]] and a
  langserver (supports sourcekit).
- +tree-sitter ::
  Leverages tree-sitter for better syntax highlighting and structural text
  editing. Requires [[module::tools tree-sitter]].

** Packages
- [[package:swift-mode]]
- [[package:swift-ts-mode]] if [[module:+tree-sitter]]
- [[package:lsp-sourcekit]] if [[module:+lsp]]
- [[package:company-sourcekit]] if [[module::completion company]]
- [[package:flycheck-sourcekit]] if [[module::checkers syntax -flymake]]
