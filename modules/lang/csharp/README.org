* Description :unfold:
This module adds C# support to Emacs, together with LSP support (via
[[https://github.com/dotnet/roslyn/tree/main/src/LanguageServer/Microsoft.CodeAnalysis.LanguageServer][roslyn-language-server]] or [[https://github.com/OmniSharp/omnisharp-roslyn][omnisharp-roslyn]]).

** Maintainers
/This module has no dedicated maintainers./ [[doom-contrib-maintainer:][Become a maintainer?]]

** Module flags
- +dotnet ::
  Enable Dotnet transient interface with Sharper
- +lsp ::
  Enable LSP support for ~csharp-mode~ and ~csharp-ts-mode~. Requires
  [[module::tools lsp]] and a langserver (e.g. [[https://github.com/dotnet/roslyn/tree/main/src/LanguageServer/Microsoft.CodeAnalysis.LanguageServer][roslyn-language-server]] or
  [[https://github.com/OmniSharp/omnisharp-roslyn][omnisharp-roslyn]]).
- +tree-sitter ::
  Leverages tree-sitter for better syntax highlighting and structural text
  editing. Requires Emacs 29.1+ and [[module::tools tree-sitter]].
- +unity ::
  Enable special support for the [[https://unity.com/][Unity game engine]] (particularly, support for
  HLSL shaders).
