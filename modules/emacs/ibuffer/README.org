* Description :unfold:
This module augments the built-in [[pkg:ibuffer]] package.

- Adds project-based grouping of buffers
- Support for file-type icons
- Uses human-readable file-size

** Maintainers

** Module flags
- +icons ::
  Enable filetype icons for buffers using [[pkg:nerd-icons]].
