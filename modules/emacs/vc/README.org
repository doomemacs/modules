* Description :unfold:
This module augments Emacs builtin version control support and provides better
integration with =git=.

** Maintainers
- [[github:hlissner]]

[[doom-contrib-maintainer:][Become a maintainer?]]

** Module flags
/This module has no flags./

** Packages
- [[package:git-link]]
- [[package:git-timemachine]]
- [[package:git-modes]]

** Hacks
- [[package:git-timemachine]] buffers will display revision details in the header-line,
  rather than the minibuffer (easier to see).

* Installation
[[id:01cffea4-3329-45e2-a892-95a384ab2338][Enable this module in your ~doom!~ block.]]

This module only requires [[https://git-scm.com/][Git]].
