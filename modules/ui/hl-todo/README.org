By enabling this module, the following keywords will be highlighted if they
occur in code comments:

- =TODO=: For things that need to be done, just not today.
- =HACK=: For brittle code that could easily break in a future update.
- =FIXME=: For broken code paths that shouldn't be forgotten.
- =REVIEW=: For impromptu code or decisions that need revisiting later (or be PRed
  upstream), usually intended to patch a temporary issue.
- =NOTE=: A comment about a code omission or the larger project (i.e. doesn't have
  much to do with the nearby code).
- =DEPRECATED=: For things that will soon be gone.
- =XXX=: There's no agreed-upon meaning for this tag. Use it however you like.
  Doom uses it to point out code differences in elisp advice.
- =BUG=: For a known bug that needs a workaround.

#+begin_src emacs-lisp
;; in $DOOMDIR/config.el
(with-eval-after-load 'hl-todo
  (setq hl-todo-keyword-faces
        `(("FOO" . ,(face-foreground "MY COLOUR HEX CODE"))
          ("BAR" . ,(face-foreground 'my-colour-var)))))
